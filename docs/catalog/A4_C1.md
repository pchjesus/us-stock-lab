# A4-C1 카탈로그 데이터 경계

SEC의 [ticker/exchange 매핑](https://www.sec.gov/files/company_tickers_exchange.json)은 CIK·이름·심볼·거래소 매핑 후보이며 완전한 현재 상장증권 목록이나 증권 유형·활성 상장 상태의 증거가 아니다. CIK는 발행인 식별자이며 주식 클래스나 증권별 식별자가 아니다. 날짜 정보가 원본에 없다면 `sourceAsOf: null`로 남기고 수집시각과 혼동하지 않는다. [SEC Fair Access](https://www.sec.gov/about/developer-resources)는 전체 초당 10회 이하, [EDGAR 지침](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)은 연락 가능한 신원 User-Agent를 안내한다. 이번 원본 요청에 예시 연락처가 사용됐으므로 응답은 폐기했고 공식 수집 성공으로 취급하지 않는다. 수집 코드는 제공하지 않으며 적법한 수집은 C2에서 해결한다.

[Nasdaq 공식 디렉터리 정의](https://www.nasdaqtrader.com/Trader.aspx?id=SymbolDirDefs)는 주기적 갱신, 테스트 심볼, 타 거래소 ETF 식별 등을 설명한다. 공개 저장소 재배포 허가 여부는 NOT VERIFIED이며 Nasdaq 원본은 수집·복제하지 않았다.

`node scripts/catalog/generate.mjs INPUT OUTPUT CHECKED_AT SOURCE_DATE|unknown`은 네트워크 없이 입력 파일을 읽는다. 출력 파일을 덮어쓰지 않으며 동일 입력·기준시각의 출력은 바이트 동일하다. 예: `node scripts/catalog/generate.mjs tests/fixtures/catalog/sec-fixture.json /tmp/catalog.json 2026-11-03T00:00:00Z unknown`. fixture는 가상 행이다. 브라우저 초기 번들에는 카탈로그를 연결하지 않는다.

거래소 대문자+심볼 원문을 ID로 사용하고 마침표·하이픈·슬래시는 별개다. 같은 CIK의 복수 클래스는 유지하고 동일 ID의 이견은 모든 행을 보류한다. 동일 행만 제거한다. 거래소 표기 별칭의 통합이나 심볼 재사용을 해결한 영구 증권 ID가 아니므로 C2에서 이력·별도 식별자 확인이 필요하다. 숫자 CIK가 없거나 잘못된 SEC 행은 제외한다. 증권 유형은 이름으로 추정하지 않고 전부 unknown, 상장은 unverified, 거래 불가다. 명시적 기존 8종목 조회는 UI 연결을 위한 참고 함수이며 일치 심볼만으로 실증권 정체성이나 거래 허용을 뜻하지 않는다.

검증 fixture 기준 입력 12, 출력 7, 형식 제외 2, 충돌 보류 2, 정확 중복 1. 공식 원본 수집·정규화/검증 상장종목은 0건이며 완전한 미국 상장종목 카탈로그가 아니다. 다음 단계는 적법한 원본 수집 및 보관 정책, 무결성 해시와 갱신 기준, 라이선스와 증권 분류/상장 상태 검증, 검색 UI 연결 및 기존 거래 허용 목록과의 안전한 매핑이다.
