# BT1 Lite 합성 백테스트

기존 `candles`의 8종목 합성 종가를 같은 날짜끼리 정렬해 사용한다. 합성 날짜는 실제 미국 거래일·휴일과 일치한다고 보장하지 않는다. 실제 시세, 운영 API, 실제 계좌와 무관한 읽기 전용 계산이다.

초기 투자금은 시작일 이후 첫 사용 가능한 날짜의 종가에 납입·매수한다. 월 적립은 시작일의 일자를 기준으로 다음 달부터이며 존재하지 않는 날짜는 그 달의 말일, 데이터가 없는 날은 그 이후 첫 합성 데이터 날짜에 적용한다. 종료일 전에 적용할 데이터 날짜가 없으면 그 납입을 건너뛴다. 종료일에는 그 이전 마지막 데이터 날짜까지 계산하며 적어도 두 날짜가 필요하다. 미래의 가격은 사용하지 않는다.

각 납입금을 현금 포함 목표 비중으로 나누고 종목별 할당 금액 안에서 정수 주만큼 그날 종가로 산다. 남은 돈은 현금으로 보유하며 이전 현금으로 재투자하거나 목표 비중으로 리밸런싱하지 않는다. 배당·분할·수수료·세금·환율·슬리피지와 소수점 주식은 미반영이다. 통화는 USD이고 모든 금액은 정수 센트로 처리하며 범위 초과는 거부한다.

각 관측일 종가에서 입금 전 포트폴리오를 평가한 뒤 납입·매수하므로, 일말 납입 기준 구간 수익률은 `(입금 후 평가액 − 납입액) / 직전 평가액 − 1`이다. TWR은 구간 수익률을 연결하고 MDD는 해당 지수의 고점 대비 최저 하락이다. 초기 금액 0, 종목 0개, 100%가 아닌 비중, 이력 범위 밖 또는 두 날짜 미만은 거부한다. 같은 입력의 결과는 결정론적이다.

현 가상계좌 복사는 기존 계좌 뷰의 평가액을 비중으로 읽을 뿐 주문·저장·원장 호출을 수행하지 않는다. 계좌의 비중을 복사해도 실제 보유 주식이나 거래 이력을 가져오지 않는다. 백테스트 결과와 입력은 화면 메모리에서만 유지된다.
