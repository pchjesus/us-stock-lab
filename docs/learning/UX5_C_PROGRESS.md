# UX5-C · 학습 진도와 오답 복습

## 제품 범위

기존 10개 학습 단원과 객관식 문항의 원문·정답·근거를 변경하지 않는다. 학습 선택 화면에 완료 수업(0~10), 현재까지 응답한 문제 수, 현재 선택 답 기준 정답률, 오답 복습 링크, 최근 수업 이어하기를 추가한다. 각 단원에서 "학습 완료"는 사용자가 수동으로 표시/취소한다. 실습을 수행했거나 퀴즈를 모두 맞혔다고 자동 판단하지 않는다.

## 데이터 계약

- 저장 위치: 브라우저 `localStorage`의 `us-stock-lab.learning-progress.v1.guest` 또는 `us-stock-lab.learning-progress.v1.user.<URL-encoded-user-id>`.
- 비로그인 기록은 로그인 사용자 기록에 자동 병합하지 않는다. 로그인 사용자의 기록 또한 같은 브라우저 안에서만 확인할 수 있으며 서버에 업로드하거나 기기 간 동기화하지 않는다.
- 버전 1의 문서: `{version:1, completed:[lesson IDs], lastLesson: lesson ID|null, answers:{[lesson ID]:{[question text]:option text}}}`.
- 읽을 때는 유효한 단원 ID, 현재 학습 자료에 실제 존재하는 질문과 선택지의 텍스트만 복원한다. 손상/구버전/너무 큰 JSON은 빈 기록으로 처리한다.
- 정답률은 **현재 선택된 답 중 정답 비율**로, 누적 시험 점수나 실습 인증이 아니다. 틀린 선택지를 맞는 선택지로 수정하면 오답 복습 목록에서 자동 제외한다.
- 브라우저 데이터 지우기 및 학습 기록 초기화는 되돌릴 수 없다. 학습 기록 초기화는 2단계 확인을 요구하고 현재 사용자/게스트 네임스페이스만 삭제한다.
- storage가 차단되면 현재 화면에서는 학습할 수 있지만 저장 실패를 표시한다. 계좌·거래·원장·관심종목·Supabase·서버 RPC·수기 기능은 읽거나 변경하지 않는다.

## 사용자 흐름

1. 학습 선택에서 진도 현황을 보고 마지막으로 살펴본 단원을 선택한다.
2. 단원을 펼쳐 개념을 읽고 퀴즈를 선택하면 답·피드백과 오답 상태가 현재 학습 프로필에 저장된다.
3. 단원 아래에서 수동으로 완료 상태를 표시한다. 완료 후에도 수정할 수 있다.
4. 진도 화면에서 오답 문항을 눌러 해당 단원으로 이동하고 정답을 다시 선택할 수 있다.
5. 기록 초기화는 수업·퀴즈 진도만 지우며 투자계좌·금융 기록은 건드리지 않는다.

## 제한 및 검증

실제 운영 인증 계정·모바일 실기기·스크린리더는 별도로 검증한다. 다른 브라우저/기기 동기화는 미지원이다. 실습을 자동 완료하는 기능은 없다. Playwright에서 기존 10개 수업 원본 해시 보존, 브라우저 저장 복원, 프로필 분리, 오답 해소, 수동 완료, 320~1440px, 금융 데이터 불변성을 검증한다.
