# US Stock Lab — UI v1.0 전면 재설계

상태: **독립 디자인 브랜치 / 기능 개발 동결 / 운영 Pages 미반영**.

## 원칙

- 사용자가 기존 가상매매 엔진·주문/원장/계좌·데이터·백테스팅/분석 산식·학습 원문과 기록을 그대로 보존하고, **화면 표현만 전면 재설계**하도록 결정했다.
- **기능 추가 작업 잠정 중단**: AC1-A1 [PR #31](https://github.com/pchjesus/us-stock-lab/pull/31) 은 Draft 상태로 보류하며 운영 Supabase migration 008을 적용하지 않는다. DATA1/PA3/BT2 및 금융 004~007 기능 확장도 중단한다.
- 디자인 검증 전에는 기존 UI를 지우거나 main에 병합하지 않는다. 전면 통합·교체 승인과 프로덕션 배포 승인은 별도로 받는다.
- 모든 실제 투자·실자금 이동은 영구 금지. 합성 가격과 실제 출처를 구별하는 안내, 기록/잔고/출처 날짜는 삭제하지 않는다.

## 교체 방식

새 디자인은 `?ui=v1`로만 활성화된다. `#...` 기존 해시 라우트는 바꾸지 않는다. URL에 옵션이 없으면 기존 UI를 그대로 제공한다.

- 신규 `src/design/v1/Navigation.tsx`: 자체 SVG 아이콘, 계층형 데스크톱 사이드바, 모바일 하단 5개 메뉴, 거래 불가 표시, 화면별 위치 안내. UI 표현만 담당.
- 신규 `src/design/v1/theme.css`: 색상 토큰, 텍스트 위계, 패널·폼·탭, 홈/시장/종목상세/포트폴리오/분석/백테스팅/학습 스타일. 기존 7만 자 `style.css`는 현재 이행 단계에서 보존하되 v1 스코프만 새 시각 규칙을 적용한다.
- `src/main.tsx`의 실제 엔진·라우팅/각 화면 호출과 `HeaderTools`의 실시간 시계·알림·지표·도움말·튜토리얼은 그대로 재사용.
- `src/HomeDashboard.tsx`는 신디자인에서만 새로운 에디토리얼 히어로 및 기존 기능의 빠른 이동 버튼을 추가한다. 원래 홈은 유지한다.

### 디자인 언어

- 따뜻하고 밝은 오프화이트 배경 `#f4f6fa`, 흰 정보 표면, 진한 네이비 제목, 코발트 `#355bd2` 주 동작.
- 장식성보다 **금액 / 수익률 / 기간 / 출처 / 다음 행동** 우선. 번호는 tabular, 과도한 카드 나열 대신 내용별 큰 구역과 조밀한 표 병용.
- 데이터 없는 항목을 0으로 보이지 않게 유지; 실제와 합성 시세를 섞지 않는다. 기존 상승/하락의 색상 의미도 변경하지 않는다.
- 데스크톱: 258px 레일(접으면 84px), 상단 시장지표·시장시계·알림·도움말. 모바일: 5개 주요 목적지 하단 탭, 별도의 설정/도구 접근.
- 모든 주요 조작 44px 이상, focus-visible 3px, 320/390/768/1024/1440px 확인, prefers-reduced-motion 지원.

### 메뉴 재분류

| 메뉴 | 기존 화면/라우트 |
| --- | --- |
| 홈 | `#home` |
| 시장 탐색 | `#market`, `#stock/<symbol>`, `#indices` |
| 내 포트폴리오 | `#portfolio` |
| 분석실 | `#portfolio/analysis`, `#backtest` |
| 학습 | `#learn`, `#learn/lessons`, `#learn/<symbol>` |
| 연습과 자료 | `#experience`, `#backtest`, `#calendar`, `#news` |
| 설정 | `#settings` (데스크톱 하단·모바일 상단 계정 링크) |

## 검증 게이트

- `tests/design-v1.spec.ts`: 신디자인 5개 해상도 및 핵심 라우트, 계좌 손익/원장 불변성, 새 사이드바·모바일 메뉴, 테마 토글 독립성, 화면 캡처 검증.
- 전체 기존 UI/Auth/Release/UX0 회귀검증을 **동일한 브랜치**에서 실행한다.
- `.github/workflows/design-v1-qa.yml`: **오직 개발 브랜치에서 실행**, Pages 배포 없음. 7개 화면 × PC/모바일 캡처를 14일간 다운로드 가능한 Actions artifact로 보관한다.
- 기존 순수 계산 파일·DB migration/함수·실제 환경 키·기존 학습 원문은 수정하지 않는다.
- 합성 가격·공식 참조의 정확성에 UI만으로 새로운 보증을 하지 않는다.
- 기본 접근성·조작 테스트로 전체 WCAG·스크린리더 실기 검증을 대신하지 않는다.

## 후속 UI 단계 (새 기능 개발 금지)

1. **Foundation(진행 중):** 전체 앱 내비게이션과 디자인 토큰, 홈 비주얼, 기존 컴포넌트의 일관된 표현.
2. **핵심 사용 동선:** 종목 개요 → 차트·주문, 포트폴리오 → 구성 분석 → 백테스팅 간 정보 위계 단순화. 렌더링만 교체하고 계산 로직은 불변.
3. **학습/자료와 마무리:** 학습 단원·퀴즈·오답 복습, 경제 일정·뉴스·모바일 레이아웃 통일, 내비게이션 테스트 및 스크린샷 검토.
4. **전면 교체 준비:** 사용자가 실제 화면을 확인하고 UX 수정, 모바일 실기기·키보드/스크린리더 검증, 기존/신규 비교를 통과하면 단일 디자인으로 전환. 한 번에 운영 변경하지 않는다.

기능 백로그는 UI 전면 개편 완료 후에만 재논의한다.
