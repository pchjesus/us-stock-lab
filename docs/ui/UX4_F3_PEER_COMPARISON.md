# UX4-F3 경쟁사 비교 후속 설계

이번 단계에서는 경쟁사 선정이나 그래프를 구현하지 않는다. 같은 섹터만으로 경쟁관계를 단정하지 않는다.

- 후보는 실제 사업 범위·제품/고객 시장의 직접 경쟁관계와 공식 공시의 이용 가능성을 근거로 선정하고 기준일·출처·검토자를 기록한다. 현재 다섯 기업만으로 비교 대상을 강제하지 않는다.
- 매출·영업이익·순이익·영업현금흐름 등 동일한 정의의 지표만 비교한다. 각 값의 원문·단위·보고/계산·정정 이력·계산식 및 입력을 연결한다.
- 회계연도 라벨뿐 아니라 실제 시작/종료일, 기간 길이, 통화, 회계 기준과 개별 지표 정의를 대조한다. 날짜가 다른 기간은 동일 기간처럼 병치하지 않고 차이를 표시하거나 비교를 보류한다. 임의 환산·TTM·누적에서 단독 분기 추정은 하지 않는다.
- 음수는 0 기준선 왼쪽, 양수는 오른쪽에 표시하고 0은 실제 보고된 경우만 사용한다. 결측은 미제공으로 표기하고 빈 값은 0으로 바꾸지 않는다. 불연속 기간은 명시한다.
- 데스크톱은 지표별 가로 막대와 해당 기간·통화·원문 링크를 제공한다. 모바일은 읽기 쉬운 요약에서 상세 팝업을 열며 포커스 이동/복귀·키보드·스크린리더를 검증한다.
- 금액 차이는 동일 정의와 기간일 때만 표시하고 방향과 단위를 밝힌다. 비율 차이는 분모가 0 또는 음수일 때 해석이 왜곡될 수 있으므로 보류하거나 별도 검증된 정의와 함께 설명한다. 변화율과 비율 차이도 혼동하지 않는다.
- 검증 가능한 경쟁관계·동일 지표·기간·통화·출처가 없으면 “비교 가능한 공식 자료 미제공”을 표시한다. 가상 수치를 실제 실적처럼 표시하지 않는다.
