# UX4-F4 표시 통화 전환

시장 및 종목 상세의 `달러 $ | 원화 ₩`는 기존 CurrencyProvider와 계정별 localStorage 키를 공유한다. 선택 상태는 설정 페이지와 즉시 동기화되며, 인증을 확인하는 동안은 비활성화한다. 저장 실패 시 기존 설정을 유지한다. 토글은 키보드 버튼·aria-pressed·44px 목표를 사용하고 reduced-motion에서는 슬라이드 전환을 제거한다.

지원 종목 8개의 목록에는 기존 `quote()` 합성 가격과 등락률을 표시한다. USD 센트로 전달한 뒤 기존 `formatDisplay()`가 USD 또는 합성 USD/KRW 1,360으로 환산한다. 합성 시세 및 실제 환전·환율손익이 아니라는 안내를 제공한다. 환율이 없거나 유효하지 않으면 미제공, 안전 정수 범위 밖 금액은 표시 범위 초과를 반환한다. 외부 참고환율이나 TradingView 설정으로 합성 환율을 바꾸지 않는다. SEC 후보에는 가격을 붙이지 않는다.

홈 관심종목·시장·종목 상세의 합성 가격과 포트폴리오 평가에 기존 통화 설정을 사용한다. 주문 확인·체결은 USD 기준이며 공식 SEC 재무자료, 기존 합성 가격·원장·수량·등락률 계산은 변경하지 않는다. 환율은 실제 환전 및 환율손익을 계산하지 않는다.
