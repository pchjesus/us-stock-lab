# UX4-F1b 근거 탐색

공식 공시는 유형·제출연도, 재무 관측은 항목명/ID·회계연도·항목·보고/계산·정정 전 포함 여부로 필터한다. 기본값은 모든 관측을 표시하며 초기화와 결과 수를 제공한다. 재무 요약 및 비교표에서 근거 확인을 선택하면 같은 기업의 근거 탭을 열고 관측 ID를 찾아 상세를 열어 초점을 이동한다. 숫자·원문·정정·산식은 기존 데이터를 사용한다.
