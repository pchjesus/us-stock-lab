# v0.9-A2-A: 오프라인 EOD 코어

A1 계약의 독립적인 순수 함수 구현이다. 현재 UI, 금융 엔진, 네트워크, 저장소에 연결하지 않는다. 테스트 값은 모두 가상이다. 실제 공급자 자료는 검토된 권한이 아직 없으므로 차단한다.

`src/eod/core.ts`는 decimal 문자열을 BigInt 정수 비율로 계산하고 등락률을 소수 여섯 자리 half-even으로 반올림한다. 독립적으로 제공된 종목 매핑 및 거래소 세션 달력을 검사하며 정규장, 이전 거래일, 통화, 공급자, 가격 및 조정 기준을 비교한다. 기업행위 연속성이 불확실하면 등락률을 보류한다. 변화율은 동일 기준 두 종가의 가격 변화율이며 배당을 포함한 총수익률이 아니다. 실관측 시각이 없으면 null로 유지한다. 거래일은 주입된 달력에 없는 경우 추정하지 않는다.

라이선스 판정은 신뢰된 기록과 사용자 범위를 입력받으며 fixture는 오프라인에서만 허용한다. 실자료는 모든 범위에서 차단하고 차단된 값이나 이전 값을 노출하지 않는다. 신뢰된 매핑과 달력은 호출자가 별도로 공급해야 하며 외부 데이터의 승인 플래그를 신뢰 근거로 사용해서는 안 된다.

이 코어는 HTTP, 공급자 어댑터, 요청 예산, 캐시, 저장 및 UI를 구현하지 않는다. `pending_release`, `unavailable`, `provider_error`는 결과 타입에 예약되어 있으며 전송 계층이 없으므로 생성하지 않는다. 정식 공급자 데이터 사용, 캘린더와 매핑 검증, 라이선스 승인 및 운영 연결은 후속 단계에서 별도로 검증해야 한다. A2-B는 오프라인 mock 공급자와 라이선스 범위에 맞는 캐시·중복 요청 방지·요청 예산을 다룬다. 금융 기능에 관측치를 전달하지 않는다.
