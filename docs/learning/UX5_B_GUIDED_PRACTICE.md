# UX5-B · 학습에서 실습으로 이어지는 안내

## 범위

기존 10개 수업의 원문, 제목, 순서, 퀴즈 정답 및 공식 출처는 변경하지 않는다. 각 단원에 교육용 실습 미션을 추가하고 실습 화면으로 이동하면 현재 미션과 복귀 링크를 표시한다. 학습 랜딩에는 이미 구현된 합성 체험실·구성 분석·BT1 백테스팅으로 이동하는 선택형 링크를 추가한다.

## 미션과 연결 대상

| 수업 | 연습 화면 | 확인 포인트 |
| --- | --- | --- |
| stock | `#stock/AAPL` | 기업 사업·재무자료·출처 |
| etf | `#stock/VOO` | ETF 전략·자료 확인 한계 |
| us-market | `#learn/AAPL` | 합성 차트 가격·기간 |
| fx | `#market` | USD/KRW 표시 전환, 공식 참고자료와 분리 |
| dividend | `#stock/AAPL` | 배당 정보 공식 확인 여부 |
| rates | `#calendar` | FOMC 예시와 공식 자료 |
| macro | `#calendar` | CPI·PCE·고용 지표의 공개 상태 |
| averaging | `#stock/AAPL` | 추가 매수 분석 또는 수업 가상 사례 |
| diversification | `#experience` | 집중형·분산형 HHI 비교 |
| news | `#news` | 출처·발행일, 미제공 상태 |

복귀는 기존 라우터를 보존하며 `#learn/lessons/<known-id>`만 인식한다. `#learn/lessons/extra` 등 미등록 경로는 기존과 같이 찾을 수 없는 화면으로 표시한다. 복귀 시 전체 필터·해당 단원 펼침·단원 초점을 복원한다.

## 저장과 데이터 경계

- 실습 미션 복귀 정보는 `sessionStorage`의 `us-stock-lab.learning-practice.v1` 한 키만 사용하며 30분 뒤 유효기간이 끝난다. 브라우저가 저장을 차단하면 직접 실습 화면 이동은 가능하지만 자동 복귀 배너는 생략한다.
- 복귀 및 안내 닫기를 누르면 해당 키를 지운다. 진도·이해도·정답·실습 성공 여부는 저장하거나 자동 판정하지 않는다(후속 UX5-C 범위).
- 주문·원장·계정·Supabase·로컬 가상계좌·관심종목은 변경하지 않는다. 합성 자료를 실제 시장 성과로 안내하지 않는다.
- 기존 사용안내, 차트 실습 기능, 계좌 및 금융 계산은 그대로 보존한다.

## 검증

10개 수업 ↔ 미션 매핑, 정상/비정상 딥링크, 이동·복귀·안내 닫기, 320/390/768/1440px 및 금융 저장 불변성을 테스트한다. GitHub Actions 결과는 PR에서 별도로 기록한다.

### GitHub Actions 실제 실행 결과

- [브랜치 QA #44073527883](https://github.com/pchjesus/us-stock-lab/actions/runs/44073527883): Pages 플래그 build, 학습 영향 26/26, 전체 UI 420/420, 인증 fixture 54/54, Release 6/6, UX0 3/3 PASS.
- 초반 QA에서 발견한 복귀 안내의 전역 `aside` 고정 레이아웃 충돌은 컴포넌트 한정 스타일로 해결했다. 재실행에서는 PC·모바일 모두 통과했다.
- 검증용 임시 workflow는 성공 실행 후 제거했다. 이후 변경은 문서만이며 테스트된 앱 소스는 변경하지 않았다.
- 실제 휴대전화·스크린리더·운영 로그인은 별도 검증 대상이고, `main`/Pages는 미변경이다.
