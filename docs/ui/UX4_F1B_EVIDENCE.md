# UX4-F1b 근거 탐색

공식 공시는 유형·제출연도, 재무 관측은 항목명/ID·회계연도·항목·보고/계산·정정 전 포함 여부로 필터한다. 기본값은 모든 관측을 표시하며 초기화와 결과 수를 제공한다. 재무 요약 및 비교표에서 근거 확인을 선택하면 같은 기업의 근거 탭을 열고 관측 ID를 찾아 상세를 열어 초점을 이동한다. 숫자·원문·정정·산식은 기존 데이터를 사용한다.

[1440px](ux4-f1b-captures/1440-evidence.png) · [390px](ux4-f1b-captures/390-evidence.png). 운영 자료를 새로 수집한 화면이 아니다. 실기기 및 스크린리더 실사용은 검증하지 않았다.

## 검증

- production build (FX·재무부 true, 수기 false): PASS.
- 신규·영향 검사: PASS. 전체 앱 322/322, Auth fixture 52/52, release 6/6, UX0 3/3 PASS. 전체 회귀 이후 검색·필터 조합, 계산식, 4개 화면 폭, 새로고침과 종목 변경 테스트를 추가해 별도 실행했다.
- 전체 앱 수는 F1a의 320 실행에 신규 검사 desktop/mobile 두 실행이 추가된 값이다. EOD 브랜치 테스트와 합산하지 않는다.
- 기존 219개 관측·200개 보고 근거·19개 계산식 보존 검사를 실행했다. UX0의 미커밋 캡처 두 파일은 검사 후 원래 내용으로 복원했다.

## F1c 키보드 및 통합 검증

관측 summary의 음수 tabindex를 제거해 기본 Tab 순서에 복귀시켰다. Chromium에서 필터 결과로 Tab 이동, focus-visible, Enter 열기, Space 닫기와 재무에서 선택한 관측의 펼침·초점을 검사했다. 재무 1440px·근거 390px을 포함해 최신 화면을 캡처해 시각적으로 확인했다.

공개 참고자료 활성화·수기 false production build PASS. 영향 검사 22/22, 최종 전체 326/326, Auth fixture 52/52, release 6/6, UX0 3/3 PASS. 전체 326은 기존 F1b 전체 322 이후 추가된 필터 조합과 F1c 키보드 테스트가 각각 desktop/mobile에서 실행된 수다. EOD 브랜치 테스트는 포함하지 않는다. 미커밋 UX0 캡처는 별도 보관 후 원래 내용으로 복원했다. Chromium 기반 검증이며 실기기와 스크린리더 실사용은 미검증이다.
