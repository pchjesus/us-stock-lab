# UX0 · 초보 투자자를 위한 디자인 기반

상태: **검토용 제안, 승인 전**. 기준 `8fdc53d0903a25c6019f6119b49427ee2616521f`, 개발 브랜치 `codex/ui-v0.8-ux0`. 운영 화면 대체·배포는 이번 범위에 포함하지 않는다. 토스증권 WTS를 연상시키는 쉬운 용어·정보 우선순위·낮은 조작 부담을 원칙으로 삼고, 외부 UI 코드·그래픽·아이콘·독점 레이아웃 자산은 사용하지 않았다. 구성과 CSS는 이 프로젝트용으로 작성했다.

## 미리보기 실행

`npm run dev:ux0` → `http://127.0.0.1:4180/prototype/ux0.html#home`.
`#stock`, `#etf`, `#learn`, `#controls`로 직접 접근할 수 있다. `npm run build:ux0`는 별도 `dist-ux0`에 빌드하고, `npm run build`의 운영 산출물에는 미리보기를 포함하지 않는다. `npm run test:ux0`로 상호작용·반응형 검증과 캡처를 재생성한다. 운영과 같은 배포용 진입점이나 Supabase SDK를 가져오지 않는다.

계좌·사용자·관심종목 저장값을 읽거나 쓰지 않는다. 홈의 관심종목 영역은 기존 다섯 기업으로 구성한 탐색 예시다. 개인 포트폴리오 수치 대신 연결 전 상태를 표시한다. 거래 화면은 실행 버튼을 비활성화하고 기존 앱으로 이동하는 링크를 제공한다. 외부 차트는 공식 링크만 제공하고 위젯·주문 연동은 후속 단계다. 시간 단위·난이도·로딩·오류 조작은 디자인 시연이며 연결 완료로 표시하지 않는다.

## 정보 구조와 기능 이동

| 현재 기능 | 제안 위치 / 보존 계약 |
| --- | --- |
| 홈 계좌 요약 | 홈 첫 카드. 운영 통합 시 기존 AccountView만 읽고 계산·복원 계약 유지 |
| 주요 지수·환율·시장 시계 | 홈은 S&P 500/NASDAQ/Dow 3개 참고값. 전체 지표·일별 참고환율은 `#indices`, 실시간 시계·헤더 6지표 팝업은 UX1에서 축약 배치 비교 후 보존 |
| 검색·관심종목 | 홈 관심종목 카드 및 기존 `#market`. A4 카탈로그 후보/기존 8종목의 거래 허용 분리 유지 |
| 기업 프로필·사업·위험 | 종목 상세 기본 ‘개요’. 핵심 문장, 수익구조, 위험 2~3개, 매출 그래프와 기간별 순이익 |
| 기존 외부 차트·가상 주문·분석 | ‘차트·거래’. PC 좌우, 모바일 세로. 실제 기존 위젯·paper/manual UI와 가격 경계는 UX2에서 그대로 연결 |
| 수기 계좌·배당·세금 | 기존 계좌 모드와 포트폴리오 경로 유지. 금융 운영 승인 전 활성화하지 않음. UI 변경으로 권한·원장 변경 금지 |
| 실적·건전성·배당 정보 | ‘재무’. 연간/직접 단독 분기 선택, 잔액 시점 구분, 배당 미확인 상태 명시 |
| SEC 원문·219관측/200근거/19계산 | ‘근거’. 출처, 제출/확인일, 기간·단위·입력값·산식·원문 근거에 접근 가능. 원본 파일 수정 없음 |
| ETF | 기업 매출 구조 대신 보유종목/자산·업종 구성/보수/분배금. 현재 VOO 예시, QQQ/SCHD 기존 상세 링크는 계속 제공하고 UX2에서 동일 틀 확장 |
| 경제 일정·뉴스·재무부 통계 | 홈 하단의 보조 링크에서 `#calendar`, `#news`, `#indices`로 연결. 삭제하거나 수집 범위를 축소하지 않음 |
| 학습 | 새 학습 랜딩 2개 목적지: 기초 투자 수업 / 인터랙티브 차트 실험실 |
| `#learn`, `#learn/{symbol}` | UX3에서 `#learn`은 랜딩, 기존 수업은 명시적 하위 경로로 이동. 기존 심볼 경로는 차트 실험실로 유지; 예전 lesson 쿼리·필터·튜토리얼 링크는 어댑터로 보존·테스트 후 전환 |
| 설정·로그인·알림·포트폴리오 | 기존 경로·소유권 유지. 알림은 UX1 공통 헤더에 남기고 새 로그인 흐름을 만들지 않음 |
| 도움말·7단계 안내 | 우측 상단 ? → 현재 화면 주제로 시작. 주제 선택 가능. 7단계 미리보기와 기존 앱의 실제 ‘사용 방법’ 경로 제공. UX1에서 기존 Tour를 연결 |

미리보기의 기존 앱 링크는 `../index.html#...`로 작성해 Pages 하위 경로도 보존한다. 별도 미리보기 빌드만 배포하면 기존 앱 링크의 대상은 포함되지 않는다. 현재 검토는 dev 서버의 같은 저장소에서 수행한다.

## 시각·상호작용 규격

- 배경 `#f4f6f9`, 정보 카드 흰색, 주 행동 `#315bd3`, 본문 `#172437`, 보조 글 `#526079`. 상태를 색만으로 구분하지 않는다. 기존 브랜드 텍스트와 독립적인 U 모노그램 사용.
- PC 220px 사이드 탐색, 최대 콘텐츠 1280px, 카드 간격 20~28px. 1000px 이하에서 탐색 180px와 단일 열 요약/거래 영역. 640px 이하에서 하단 탐색·단일 열, 좌우 여백 16px.
- 제목 34~42px, 절 제목 21px, 본문 15px. 숫자는 tabular-nums. 긴 숫자·URL·회계 근거는 줄바꿈하고 전체 값을 생략하지 않는다.
- 선택: 종목/계좌는 라벨 있는 native select. 수기 항목은 미활성 설명과 disabled. 실적 기간/학습 난이도/시간 단위는 aria-pressed가 있는 버튼 그룹. 버튼 그룹은 Tab/Enter/Space로 조작하며 탭 패널 키보드 계약을 가장하지 않는다.
- 주요 행동: 한 영역에서 파란 버튼 1개 중심. 보조는 흰 배경 테두리, 출처는 밑줄+새 탭 표시, 재조회는 명확한 문구와 반복 화살표. 모든 조작 타깃 최소 높이 44px, 키보드 focus ring 3px.
- 미제공: 회색 점선 패널+‘확인 필요/미제공’, 0과 구분. 로딩은 메시지, 오류는 원인 범주+다시 확인 행동, disabled는 이유를 함께 표시한다. 실제 0은 검증된 숫자로 표시한다.
- 매출은 실제 회계기간별 막대, 이익 변화는 같은 기간의 정확값 목록. 기존 그래프의 누락 분기 간격을 유지한다. ETF 구성비 자료가 없으면 도넛이나 임의 배분 그래프를 그리지 않는다. 공식 출처 근처에 단위·기간, 합성 값 근처에 ‘실제 시세 아님’ 표시.
- 화면 내용 전환 250ms opacity/5px 이동, 버튼 상태 200ms. prefers-reduced-motion에서는 전환 제거. 자동 진행·과한 진입 효과 없음.
- 도움말은 native dialog, ESC·포커스 복귀·body 스크롤 잠금. 문서 길이는 모달 내부에서 스크롤. 색 대비는 명시 색상과 읽기 확인을 기준으로 설계했으며 전체 WCAG 감사·스크린리더 실기 검증은 NOT VERIFIED.

## 현재 자료로 표현 가능한 범위

5기업의 검증 프로필·사업·위험·수익구조, 재무 219관측/200근거/19계산 및 원문 URL/회계기간/금액 단위를 재사용한다. 현재 데이터는 저장 당시 검증 범위이며 최신 공시를 새로 수집하지 않는다. ETF 3종 이름·분류·설명·공식 상품 링크, 기존 8종목 합성 가격/캔들·시장 예시 지표를 명시적 합성 라벨과 함께 사용할 수 있다. 계좌 연결 전에는 개인 자산을 추정하지 않는다.

추가 확인 필요: ETF 최신 보유종목/구성비·보수·분배금/기준일, 5기업 배당 사실, 실시간 지수·가격과 이용 조건, 사용자 실제 계좌 상태, A4 카탈로그의 증권 유형·상장 상태·수집 이용 조건. 미확인 내용을 카드에 채우거나 0으로 대체하지 않는다.

## 승인 후 구현 순서

- **UX1 공통 구조:** 토큰/공통 컨트롤·반응형 탐색·문맥 도움말·기존 알림/시계/지표판/Tour 연결. 기존 hash 경로와 초점/스크롤 회귀를 먼저 고정.
- **UX2 상세:** 기업 개요/차트·거래/재무/근거 분리와 ETF 전용 구조. 219관측·200근거·19계산 보존 검사, 기존 paper/manual 계약 및 거래 비활성 게이트 회귀. ETF 미확인 항목은 그대로 유지.
- **UX3 홈·학습:** 실제 AccountView·watchlist를 새 홈에 연결하고 수업/ChartLab 진입을 분리. 기존 학습 링크/필터·모바일 하단 탐색·외부 실패·저장 복원 검증. 디자인 승인과 운영 반영 승인을 거친 후 별도로 통합.

이번 체크포인트는 디자인 구조 검토이며 승인·운영 통합은 완료되지 않았다. 기존 앱의 구조적 리팩터링은 보류한다. 별도 진입점이므로 기존 금융 상태 소유권을 바꿀 근거가 없다.
