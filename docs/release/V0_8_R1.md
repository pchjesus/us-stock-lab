# v0.8-R1 UI 공개 후보 검증

2026-11-03 UTC. 기준 개발 HEAD `d536d0415c2004d3e01ae893611c696e8c888be2`, main `ac8358ae6d370367d1091ea3abc3bb4f399689b3`. 시작 시 개발 브랜치 clean. 버전 `0.8.0-rc.1`, 화면 `v0.8 · UI 후보`.

**판정: UI Pages 공개는 조건부 GO.** 별도 사용자 승인 후 main 반영과 수동 Pages 배포만 진행한다. `VITE_ENABLE_MANUAL_TRADING=false`를 유지한다. 금융 migration 004~007 적용과 수기 기능 운영 활성화는 이번 승인 범위가 아니며 G1-C3 NO-GO를 유지한다.

## 수정 및 보존

- 로그인 사용자의 저장된 수기 모드가 미적용 RPC를 호출할 수 있었다. 빌드 시 기본 off인 표시 게이트로 수기 선택·Workspace 마운트를 막고 `공개 준비 중`으로 표시한다. 저장된 선호는 보존한다. 직접 API 호출을 통제하는 서버 보안 장치로 간주하지 않는다.
- Pages workflow에 수기 게이트 false를 명시했다. workflow_dispatch만 사용하고 build/deploy 단계에서 SQL·migration·Cron 실행은 없다. 이번에 workflow를 실행하지 않았다.
- 기존 로컬·서버 paper, 주문/원장 계산, 수기 금융 구현, 001~007 SQL, 원자 배포 도구, 5기업 219관측/200근거/19계산 및 ETF 원본은 변경하지 않았다. 수기 테스트 서버만 명시적 true로 실행해 기존 기능을 계속 검사한다.
- 합성 가격·지표는 합성 표시를 유지하고, 공식 대기 모드는 값 미제공, 실제 일별 참고환율은 별도 출처·기준일을 표시한다. 신규 시세 API나 종목은 추가하지 않았다.

## 이번에 실행한 검증

Node 24.19.0 / npm 11.9.0 / 시스템 Chromium. Pages workflow의 공개 환경변수와 동일하게 빌드했다. 재현 명령(저장소 루트):

```bash
python3 - <<'PY'
import os, re, subprocess
from pathlib import Path
env = dict(os.environ)
for key, value in re.findall(r'^\s+(VITE_\w+): (.+)$', Path('.github/workflows/pages.yml').read_text(), re.M):
    env[key] = value.strip("'\"")
subprocess.run(['npm', 'run', 'build'], env=env, check=True)
PY
npx playwright test --config playwright.release.config.ts
npm test
npm run test:auth
git diff --check
```

## 현재 운영과 공개 조건

- Supabase `vveljtqmujdzkzmoncjx` 읽기 전용 재확인: Foundation 및 001~003만 이력 존재, 004~007 없음. auth.users / paper_accounts / paper_orders 각 0, manual_accounts 없음. 운영 쓰기 작업과 실제 paper_snapshot 호출은 하지 않았다(계좌를 생성할 수 있음).
- 실제 Pages 홈은 HTTP 정상, 자산 `assets/index-k_9-kUpN.js`에 구버전 v0.4-B 표시가 남고 신규 헤더 지표판·차트 패널이 없다. 현재 main SHA는 별도 조회값이며 **실제 배포 SHA는 NOT VERIFIED**다. 사이트/배포 설정 API가 도구에서 지원되지 않아 정적 응답과 실제 브라우저를 확인했다.
- 미적용 수기 RPC는 게이트로 호출되지 않으며, 기존 paper 경로는 그대로 유지한다. 실제 운영 인증 검증 없이 UI 회귀와 읽기 전용 DB 조회만으로 기존 서버 전체를 다시 PASS 판정하지 않는다.
- 공개 후 TradingView/통계·환율 제공자의 네트워크·정책·사용자 팝업 설정에 따라 실패할 수 있다. 기존 오류 안내/공식 링크/미제공 상태를 유지한다. 합성 가격과 외부 가격은 주문에 혼합하지 않는다.
- A4/A5 전체 미국 상장종목 카탈로그·거래 허용 목록 분리는 미완료. 기존 8종목만 유지, 자료 이용 조건과 증권 유형/현재 상장 상태 검증 후 별도 진행한다.

다음 승인 범위: 이 Draft PR의 UI 후보를 main에 반영하고, 수기 false 설정으로 기존 Pages workflow를 수동 실행한 뒤 비로그인 PC·모바일 smoke를 수행한다. DB/금융/Cron/Auth 설정 변경은 포함하지 않는다. 이번에는 main 병합과 Pages 실행을 하지 않았다.

공개 후 회귀가 발생하면 운영 DB를 변경하지 말고 공개를 중단한다. 실제 마지막 성공 Pages 실행의 commit/artifact를 먼저 확인한 뒤, 별도 승인으로 그 버전의 정적 사이트를 다시 배포한다. 현재 배포 SHA를 추정해서 rollback하지 않는다.
