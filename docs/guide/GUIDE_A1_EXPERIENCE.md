# GUIDE-A1 합성 데이터 체험실

도움말과 기존 7단계 사용 방법에서 `#experience`로 진입한다. 거래·구성·성과의 세 탭을 클릭 또는 방향키로 자유롭게 이동하며 체험 상태는 이 화면의 메모리에만 남는다. 화면 이탈이나 새로고침 시 초기화된다.

합성 예시 계좌는 $100,000, AAPL $100, VOO $50으로 시작한다. `applyTrade`의 순수 계산으로 체험 계좌에만 매수·매도한다. 주문 제출, 계좌 저장, 사용자 원장이나 인증 상태 변경 경로에 연결하지 않는다. 분산·집중 예시와 체험 계좌는 기존 PA1 구성·집중도·비중 실험을 사용한다. ETF 내부 구성은 추정하지 않는다.

성과 탭은 PA2 CSV 계약에 맞는 고정 synthetic 데이터와 기존 파서·분석·그래프를 사용한다. 예시 수익률은 실제 시장 성과가 아니며, CSV 형식 안내와 별도 분석실 링크를 제공한다. 체험 탭은 고정 합성 자료만 표시하고 사용자의 파일은 실제 분석실에서 별도로 불러온다.

## 검증

Pages 플래그 build 및 TypeScript PASS. 초기 영향 검사 40건과 최종 체험실·PA1·PA2·도움말 26건, Auth fixture 54건 PASS. 전체 UI는 395건 통과·1건 실패했으며 실패한 기존 헤더 가상 시계 검사는 `Cannot fast-forward to the past`로 종료됐고 단독 재실행 시 양 프로젝트 2건 PASS. 초기 전체 실행은 진행 중 빌드를 교체해 탐색 2건이 실패하여 중단하고 새 빌드에서 재실행했다. 320·390·768·1440px 및 계좌·관심종목 저장값 불변, 학습 중 금융 RPC 0건을 확인했다. 실기기와 운영 계정은 미검증이며 Release/UX0 전용 회귀는 실행하지 않았다.
