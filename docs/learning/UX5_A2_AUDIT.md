# UX5-A2 기존 수업 감사

기존 열 개 수업의 ID, 단계, 제목, 본문, 실습 문구는 원본 배열에 보존한다. 아래는 교육 확장의 우선순위이며 기존 문구가 구현된 기능의 완전한 설명이라는 뜻은 아니다.

| ID | 학습 목표 및 앱 연결 | 부족한 부분과 후속 조치 |
| --- | --- | --- |
| stock | 지분과 손실을 이해하고 시장에서 기업 관찰 | A1 확장 완료. 예시와 위험 설명을 유지하고 후속 복습 설계 필요 |
| etf | 펀드와 분산을 이해하고 VOO·QQQ 상세 확인 | A1 확장 완료. 비용과 집중 위험을 계속 명시 |
| us-market | 가격에 영향을 주는 요인과 합성 차트 관찰 | 시장가격과 합성 데이터의 차이, 체결 구조를 더 설명 |
| fx | USD/KRW와 원화 평가액을 구분하고 표시 토글·지표 관찰 | P1에서 합성 1,360원과 별도의 공개 참고환율, 환전 미구현을 명시 |
| dividend | 배당과 가격 변동을 구별하고 기업 자료 확인 | P1에서 일정·총수익·합성 계좌와 Pages 수기 기능 제한을 설명 |
| rates | 금리와 기업·투자자의 관계, 캘린더 관찰 | 금리와 주가의 인과관계가 단순하지 않음을 사례로 보강 |
| macro | CPI·PCE·고용과 캘린더 자료 구분 | 참고자료의 출처·발표 시각·개정 여부와 미제공 상태 보강 |
| averaging | 추가 매수와 평균단가, 상세 분석 관찰 | 더 많은 투자금과 손실 가능성, 분석과 주문의 차이를 수치로 보강 |
| diversification | 개별 위험과 시장 위험, 관심종목 관찰 | 종목 수만으로 분산을 보장하지 않는 사례 추가 |
| news | 출처·시각·사실과 해석을 구별 | 자료의 확인일과 정보의 불확실성, 원문 확인 실습 보강 |

Pages 빌드 설정에서 공개 환율 참고자료는 활성화하고 수기 거래는 비활성화한다. 별도 수기 계좌의 배당 처리 코드가 존재한다는 사실은 공개 Pages에서 사용 가능하다는 뜻이 아니다. 기본 합성 계좌의 배당 지급이나 실제 환전·환율손익을 구현된 것으로 안내하지 않는다. 수업의 진도 저장·복습은 UX5-C 범위다.
