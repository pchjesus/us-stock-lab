# UX4-F3c 경쟁사 비교 UI

NVIDIA 재무 탭의 매출 그래프 아래에서 기존 Modal을 열어 AMD의 매출·영업이익·순이익·영업현금흐름을 선택한다. 다른 기업과 ETF에는 진입점을 표시하지 않는다. F3b `peerFacts`와 `comparePeerFacts`의 판정을 사용한다. 공식 공시 기준 경쟁 범위는 GPU·가속 컴퓨팅·데이터센터 제품이며, 연결 실적 전체가 동일한 사업은 아니다. 각 카드에는 FY·실제 기간·US GAAP·원본 금액·accession 및 공식 10-K를 제공한다.

실제 NVDA FY2026과 AMD FY2025는 364일씩이지만 종료일이 29일 달라 동기간 비교를 보류한다. 팝업은 그래프 앞에 해당 사실을 안내하고 상대 크기 막대·차액·배율·우열을 표시하지 않는다. 규모는 기업 가치 평가나 투자 추천이 아니다. 데이터 신뢰 또는 검증 실패도 비교를 표시하지 않고 쉬운 말로 안내한다.

동일한 실제 기간과 F3b의 모든 조건을 통과한 결과만 공통 축 가로 막대와 정확 차액을 그릴 수 있다. 중앙선 0, 음수는 왼쪽, 양수는 오른쪽이며 실제 0은 점으로 표시한다. 결측·부적격에서는 그래프를 만들지 않는다. 막대 길이는 BigInt 정수 비율에서 산출하고 크기가 제한된 픽셀만 Number로 변환한다. 검증에 사용한 동일 기간 데이터는 테스트 전용 가상 fixture이며 실제 화면에 공급하지 않는다.

모달은 기존 Modal의 닫기·ESC·포커스 복귀 및 본문 스크롤 잠금을 사용하며, 모바일에서 카드를 세로로 배치한다. 기존 금융·종목·계좌·F3b 데이터는 변경하지 않는다.
