## 구조 변경

이전: 8개 동등 카드 → 매출 그래프 → 중복 재무건전성 목록.
이후: 매출·영업이익·순이익·영업현금흐름 4개 요약 → 매출 그래프 → 손익계산서/재무상태표/현금흐름표의 최대 3개 검증 기간 비교 → 배당 안내. 각 비교표의 원본값은 펼쳐 확인하고, 용어 설명과 최근값 상세는 접어 반복을 줄인다.

요약 축약 금액은 BigInt 정수 부분을 단위별 소수 한 자리에서 절삭한 표시다. 원본 decimal 문자열은 상세에 그대로 표시한다. 기간 실적은 기존 latestFinancialFact가 선택한 동일 회계기간을 사용하며 분기 현금흐름을 연간 값으로 보충하지 않는다. 재무상태표는 시점 자료임을 별도 표기한다. 비교표는 검증·현재 관측만 선택하고 누락은 미제공으로 표시한다. 기간 불연속 가능성을 알리며 보간·성장률·TTM·신규 비율을 만들지 않는다.

## 접근성과 근거 연결

기존 overview-/financial- testid, 근거 탭 data-fact-id, SourceLink 및 FactEvidence를 유지한다. 재무 요약·상세·표의 data-observation-id는 FinancialFact.id와 연결된다. F1b에서는 이 ID로 근거 탭 필터/이동을 구현할 수 있다. 현재는 원문 링크와 상세 펼침만 제공한다. 표의 caption과 행/열 scope 헤더, 키보드 초점 가능한 가로 탐색 영역을 추가했다. 기존 그래프의 0·음수·누락 구분 및 title/기간/정확값/출처를 보존하고 작은 화면에서는 가로 탐색한다. 새 애니메이션은 없다.
