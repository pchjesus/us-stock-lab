# UX4-F3a 재무 금액 표시

원본 FinancialFact와 감사용 `financialValueText()`는 변경하지 않는다. 표시용 함수는 USD를 1만·1억·1조 달러 단위로 축약한다. 단위 선택 후 소수 첫째 자리에서 절반 이상을 절대값이 커지는 방향으로 반올림하며, 반올림이 다음 단위 경계에 도달하면 큰 단위로 다시 표시한다. 예: `416161000000 USD` → `4,161.6억 달러`, `999999999999 USD` → `1.0조 달러`. 1만 달러 미만은 원본 소수 자릿수를 보존하고, 주당 USD는 원본 자릿수를 보존해 `7.46달러/주`로 표시한다. 음수·0·누락을 구분하며 잘못된 문자열은 미제공이다.

정수와 소수 자릿수는 BigInt로 처리하고 표시값을 계산·주문에 사용하지 않는다. 요약·개요·비교표·그래프는 축약값을 표시하며 접힌 상세에서 원본 decimal, 관측 ID, 기간, 공식 URL, 원문 필드와 계산식/입력에 접근한다. 그래프 막대의 기존 시각적 높이 계산은 유지하며 표시용 decimal 변환과 별도다.
